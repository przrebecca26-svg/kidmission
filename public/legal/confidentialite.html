Politique de confidentialité

KidMission — Version 17 novembre 2026

1. Qui est responsable

Le parent qui crée le compte est le responsable des données saisies pour sa famille. KidMission traite ces données uniquement pour fournir le service.

2. Données collectées

  • Compte parent : email, nom affiché, mot de passe (hashé).
  • Profils enfants : prénom, type de récompense, identifiant de connexion, code (hashé).
  • Activité : missions déclarées, bonus, malus, jokers, récompenses, versements, soldes.
  • Données techniques minimales pour le fonctionnement (authentification Firebase).

3. Données des enfants

Les profils enfants sont créés uniquement par le parent. Aucune donnée n’est collectée directement auprès des enfants sans l’intervention du parent. L’enfant ne peut pas créer de compte seul.

4. Utilisation des données

Uniquement pour : authentification, affichage des missions et soldes, historique familial, et fonctionnement de l’application. Aucune revente de données. Aucune publicité ciblée.

5. Stockage et sécurité

Données stockées dans Firebase (Google) en région Europe. Accès strictement limité à la famille concernée grâce aux règles de sécurité.

6. Export des données

Depuis les réglages du compte parent, tu peux télécharger un export de toutes les données de ta famille (format JSON).

7. Suppression de compte

Tu peux demander la suppression complète de ton compte et de toutes les données associées (profils enfants, historiques, etc.) depuis les réglages. La suppression est définitive. Une confirmation est demandée. Les données sont effacées dans un délai raisonnable.

8. Tes droits

Accès, rectification, suppression, portabilité. Contacte-nous via l’application ou l’email du compte pour exercer ces droits.

9. Contact

Pour toute question relative à tes données : utilise l’adresse email de ton compte parent ou les moyens indiqués dans l’application.
